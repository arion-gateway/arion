# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/arion-gateway/arion/security/advisories/new): choose **Report a vulnerability** in the repository's Security tab. The report is visible only to the maintainers.

Never report a suspected vulnerability in a public issue, discussion or pull request. If you are unsure whether something is a security issue, report it privately anyway.

Please include:

- The Arion version or commit, and the deployment mode
- The smallest configuration that exhibits the problem, sanitised
- The impact as you understand it
- Steps to reproduce, or a proof of concept if you have one

## What to expect

We are a small team and respond on a best-effort basis: we read every report, acknowledge it as quickly as we can, and keep you updated while we assess it. Confirmed vulnerabilities are fixed in the latest release and published as a GitHub security advisory, with a CVE where warranted. We credit reporters in the advisory unless they prefer otherwise.

## Coordinated disclosure

Please keep the details of a report private until a fix is released and the advisory is published. We will work with you on timing, and we will not take action against good-faith research conducted under this policy.
